4.	Follow a value from Python to HTML
We ran the code and found the new message in the browser.
Then we changed the message string in Python to 'Welcome to our workshop website'.
    Where is the message defined?
The message is defined in Python, inside app.py, in the render_template() function.
    Where is it displayed?
It is displayed in the HTML file templates/index.html, inside the <p> tag. On the web page, it appears at the top before the header. 
    Does the browser receive the curly-brace expression or the message text?
The browser receives the message text ("Welcome to our workshop"), not the curly-brace expression ({{ workshop_message }}), because Flask replaces {{ workshop_message }} with the value sent by Python.
